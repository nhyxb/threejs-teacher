# Three.js 机制教学

把知识变成学习者能观察、操作和验证的机制。默认中文、零基础、一个知识点、文字分步讲解，交付交互网页。用户输入是教学目标，由 AI 编程工具生成独立课件；课件本身不调用 AI API。

默认界面保持精简：单列 3D 演示、播放与进度、当前步骤一句重点、前后按钮。参数、完整讲解和统计通过原生折叠区域按需查看，最后一步预测自动展开。不要生成常驻侧栏、仪表盘指标卡、重复品牌文案或横排的完整步骤导航。

## 先确定要讲清什么

从请求提取一个可检验的学习目标和必要前置概念。用户只给知识点时，自主选择合适范围并说明；仅当对象歧义、难度或目标会实质改变内容时澄清。宽泛题目选一个有代表性的机制，不把整个学科塞入一个场景。

使用用户资料或可信的一手资料核验机制、公式、单位和适用条件。在线检索不可用时标明未核验的部分，避免把未经查证的硬件规格或性能数字写成事实。把来源和教学简化记入 lesson.md，并在课件“模型假设与参考资料”中给出简明说明。

读取 [教学设计](references/teaching-design.md)，再写步骤：每一步说明“要理解什么、画面改变什么、学习者能操作什么、如何知道理解了”。不要求固定步骤数；通常 3–6 步足够。先说明现象，再解释内部机制，随后改变一个有意义的变量，最后预测并验证。

## 选择能解释它的画面

读取 [视觉语言与质量标准](references/visual-language.md)。优先采用结构拆解、过程路径、截面、运动、前后对比或可操控参数。不要把所有知识点套成发光球、无关粒子、旋转模型或文字展板。

使用 Three.js 解释空间或过程，使用 HTML/SVG 表达中文、公式、清晰标注与图表；不适合三维的关系允许以二维配合。颜色对应明确语义，路径与箭头须有图例或文字说明。默认独立实验台，无书本外壳。视频参考仅作为视觉方向，不作为科学事实来源。

## 创建课件

运行环境：Node.js 22.12+、npm、能操作文件与终端的 AI 编程工具；视觉验收还需浏览器。无需专有 MCP、账号、API Key、在线字体或语音服务。

根据本技能的实际路径运行：

```sh
node <skill-dir>/scripts/create-lesson.mjs <output-dir>
```

脚本仅写入不存在或空的目标目录，不覆盖现有工作。模板自带可运行的杠杆示例；生成新知识点时替换主题、模型、来源和测试，不能仅改标题。随后在新课件目录执行 `npm ci`。

读取 [模板接口](references/runtime.md)。修改主要集中在 `src/lesson.ts`、独立纯模型和模型测试；按内容调整场景，保留通用控制器。不要为了省事复制主题到多处、引用模板目录外的源码或把宿主 AI 工具 API 写入课件。

- 由模型或不可变事件产生唯一派生状态，同步驱动场景、文字和统计。
- `updateAt({stepId,time,params})` 中 time 是当前步骤内秒数；同样输入必须得到相同结果。禁止让随机值、帧率或 `+=` 累加决定教学结果。
- 参数改变时重算当前实验，清空旧轮状态；跳步、拖动进度和重播都走同一更新路径。
- 相机可自由观察，自动讲解视角不能持续抢夺用户控制。提供恢复视角。
- 参数、问题和反馈要解释因果；答错时说明原因，不能只有红色或“错误”。
- 预测题依赖参数时用动态 question；参数改变后清除旧答案。检查零值、相同比例等边界是否仍有唯一答案，避免画面在作答前泄露待预测结果。

不依赖本技能包之外的其他技能。工具具备浏览器、搜索、截图能力时直接使用；工具不同只改变操作方法，不改变交付要求。

## 有针对性地验证

执行 `npm test` 和 `npm run build`，测试实际模型的核心行为与边界，不测试文案是否包含某句话。实际启动课件，在浏览器检查：初始场景、步骤切换、播放暂停、拖动进度、参数变化、预测反馈、重播与镜头。至少对两个时间点往返跳转，确认场景和数值一致。

查看桌面、平板、手机宽度（建议 1440/768/390）的截图：中文可读、无横向溢出、关键标签不遮挡、手机可触达控制。读取浏览器控制台，确认没有运行时异常。视觉问题应修复后再截屏。

若浏览器不可用，仍完成构建与模型验证，但明确报告“未完成浏览器与视觉验收”，不能把构建通过当作画面验证。低性能优先减少装饰、后处理与像素比，保留教学信息。

交付源码、锁文件、dist、lesson.md、预览截图和实际验证结论。说明启动方法、学习目标、模型边界与未完成检查。按请求打包；不要把 node_modules、凭证、工具缓存或参考原视频放入包内。可迁移安装见 [工具适配](references/installation.md)。
