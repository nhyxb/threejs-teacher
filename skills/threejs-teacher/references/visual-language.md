# 三维教学的视觉语言

采用立体科学插图的表达方式，优先用结构拆解、因果路径和同步数值帮助理解。展示片中快速切换多个装置的节奏，不适合直接用作完整课程的讲解节奏。

## 观察与迁移

| 视觉表达 | 教学用途 |
| --- | --- |
| 浅色立体模型、细轮廓与排线 | 用形体和边缘表现结构；排线只是可选材质 |
| 柔光与接触阴影 | 建立空间层次，避免复杂后处理抢走注意力 |
| 少量高饱和流带与透明量筒 | 为路径、状态、大小建立稳定颜色语义与数值反馈 |
| 装置剖开、镜头推进内部 | 关键机制放大或拆解；保留恢复全景的入口 |
| 下方步骤、字幕与导航 | 中文分步说明与学习者可控的播放过程 |
| 书本和翻页 | 删除，改成独立实验场景 |

优先机制演示，材质按知识点选择。参考素材只用于理解视觉语言，不逐帧复制，也不把第三方视频或截图打包成模板资源。

## 实现选择

原生几何体、ExtrudeGeometry、EdgesGeometry、透明或剖切适用于结构示意；路径可用曲线、箭头或实例化小单元。仅在真正解释过程时添加粒子。不要用玻璃、霓虹或 Bloom 代替机制设计。

透明物体容易产生深度排序错误；能用开口、剖切或分离结构表达时优先使用。重叠线条过多时，减弱非重点边缘，而不是让所有边缘同样黑。

标签绑定世界坐标，并检查默认视角、用户旋转和手机视角。正文无需随相机运动。数据在搬运时复制/移动的含义应由模型决定，避免把“读取副本”误画成源数据消失。

## 截图检查

能否从静止画面识别对象、当前动作和结果？颜色有没有可解释的含义？流带是否对应本次事件？数字与显示的对象是否相符？模型边界是否可见？去掉全部装饰后，因果关系是否仍然成立？

检查完整过程至少三个关键状态：开始、动作中、结果。只看漂亮的初始帧不足以验收。
