# 齿轮：齿数怎样改变转速

面向零基础的中文交互课件，基于 `threejs-teacher` 模板构建。

学习目标：给定两只外啮合直齿轮的齿数与输入转速，预测输出转速及转向，区分传动比与实际转速，并用数齿、数圈和参数实验验证。

## 运行

需要 Node.js 22.12+、npm 和支持 WebGL 2 的浏览器。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

`dist/` 是可独立部署到 HTTP 静态服务器的产物。默认不部署；不能直接双击 file:// 代替静态服务。课件运行不需要账号、AI API、网络字体或在线资源。使用锁定依赖，通过 npm ci 安装。

## 教学步骤

| 步骤 | 理解什么 | 画面变化 | 操作与验证 |
| --- | --- | --- | --- |
| 认识两轮 | 输入主动、输出被动；齿数与 rpm | 青色/橙色实体齿轮、白色数圈标记 | 播放，比较默认 12→24 齿的圈数 |
| 为什么反转 | 外啮合转向相反 | 理论节圆相切处的同向箭头 | 暂停观察；切换输入方向 |
| 数齿与圈数 | 同一时间经过相同数量的齿 | 累计圈数与通过齿数同步 | 只把输出 12→24→36，保持输入不变 |
| 算出转速 | 输出速率 = 输入速率 × z₁ / z₂ | 转速、传动比和角度由同模型计算 | 改 rpm；测试 0 rpm |
| 预测并验证 | 大小、比例、方向组合判断 | 初始隐藏结果，提交后揭示 | 当前参数生成题目，改参数清空旧答案 |

参数：两轮齿数各可选 12/18/24/36；输入速率 0–120 rpm，间隔 5；输入顺/逆时针。可跳步、播放/暂停、拖动进度、重播、自由旋转缩放和恢复讲解视角。每步时间从零开始；不自动跳下一步。演示速度倍率只影响观看速度。

## 模型与适用条件

- 两只平行轴、同模数的外啮合理想直齿轮；忽略摩擦、间隙、弹性、惯性、负载和损耗，不讨论扭矩。
- z₁/z₂ 为输入/输出齿数；n₁/n₂ 为有符号转速，单位 rpm。统一从齿轮上方看，顺时针为正，逆时针为负。
- n₂ = −n₁ × z₁/z₂；传动比 i = z₂/z₁。i>1 减速，i<1 增速，i=1 等速。静止时仍显示几何齿数比，避免计算 0/0。
- 当前步骤模拟时间 t（秒）内，累计圈数 = n × t/60；通过的完整齿数取 |输入圈数|×z₁ 的下整值。
- 模数采用教学世界单位 0.12，节圆半径 r=mz/2，中心距 r₁+r₂。改齿数时自动调整轴距；轴、厚度和桌面不是实际比例。
- 齿形为可数齿的示意轮廓，并非制造用渐开线；运动比来自解析模型，不由碰撞/物理引擎计算，不解释齿面滑动与接触力。
- 圆环表示理论节圆，箭头表示节圆相切处的运动，白色径向线帮助数圈。色彩同时配中文标签。
- `deriveGearState` 是纯模型。场景、说明和读数来自同一状态；角度由绝对时间计算。`revealed` 是显式的答案揭示视图状态，不推进模拟时间。

## 实际验证

- 模型 7 项测试通过，覆盖减速/等速/增速、反向与零输入、节圆线速和角位移、时间/参数往返、非法输入、预测选项唯一性。
- TypeScript 检查及生产构建通过。
- 在浏览器检查了五个步骤、播放/暂停、进度拖动、参数重置、预测反馈、重播与镜头复位。
- 桌面、平板与手机宽度下检查过布局；手机最大 36+36 齿组合可完整显示。最终精简界面无横向溢出或浏览器运行时异常。
- 未做真实移动设备 GPU 性能测试。高 rpm 可能出现视觉混叠，可用 0.5× 播放速度、暂停和拖动辅助观察。
